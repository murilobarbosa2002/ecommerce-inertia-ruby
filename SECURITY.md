# Política de Segurança

## Reportando uma vulnerabilidade

Se você encontrar uma vulnerabilidade de segurança neste projeto, **não abra uma issue pública**. Em vez disso, envie um e-mail para [murilobarbosa2692@gmail.com](mailto:murilobarbosa2692@gmail.com) com:

- Descrição da vulnerabilidade e impacto potencial.
- Passos para reproduzir (ou prova de conceito).
- Versão/commit afetado, se souber.

Você pode esperar uma resposta inicial em até alguns dias úteis. Pedimos que aguarde a correção/divulgação coordenada antes de tornar o problema público.

## Versões suportadas

Como o projeto ainda está em sua fase inicial de fundação, apenas a branch `main` recebe correções de segurança. Isso será revisado quando o projeto atingir uma primeira versão estável.
