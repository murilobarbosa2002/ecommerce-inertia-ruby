# 0006 - Licença open source MIT

## Status

Aceito

## Contexto

O projeto é um template white-label (reutilizável para e-commerces de nichos diferentes). Havia duas formas de posicionar essa reutilização:

1. Manter o projeto de uso restrito/privado, cujo reaproveitamento para outros negócios dependeria de autorização do autor caso a caso.
2. Publicar o projeto como um **template open source de e-commerce**, sob uma licença permissiva, deixando explícito que qualquer pessoa pode usar, modificar, redistribuir e vender soluções baseadas nele, sem pedir permissão.

A segunda opção é mais coerente com um projeto bem documentado e revisável publicamente, e evita qualquer ambiguidade sobre o que terceiros podem ou não fazer com o código.

## Decisão

O projeto é licenciado sob **MIT** (arquivo `LICENSE` na raiz). Uso, modificação, redistribuição e venda de produtos/serviços baseados neste código são livres, sem necessidade de autorização, sujeitos apenas aos termos padrão da MIT (preservar o aviso de copyright e a licença, e isenção de garantia).

## Consequências

- Qualquer pessoa — incluindo o próprio autor, em projetos para negócios reais — pode clonar este template e adaptá-lo livremente para um nicho específico, sem fricção legal.
- Nenhuma informação sobre uso real/comercial do template por terceiros precisa (ou deve) ser documentada neste repositório público — o repositório descreve o template em si, de forma genérica, não quem o está usando ou para qual negócio.
- Não há garantia nem responsabilidade do autor sobre o uso que terceiros fizerem do código (termo padrão MIT).
- Contribuições de terceiros (se aceitas no futuro) herdam a mesma licença.
